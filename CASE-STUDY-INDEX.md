# Case Study Index

This index converts the complete Drive evidence audit into a portfolio build queue. Employer-related stories will be anonymised and independently reconstructed. Owned ventures will receive separate confidentiality reviews.

The portfolio will not begin with Lynr or ThinkBud. It will first establish the operator body of work accumulated across Marketing Operations, Revenue Operations, systems, data, analytics, transformation and AI.

## Case-study types

| Type | Purpose |
|---|---|
| **Flagship operating system** | Shows an end-to-end model that connects strategy, process, systems, data and governance |
| **Transformation case** | Shows diagnosis, decisions, delivery, adoption and outcomes in an anonymised context |
| **Leadership system** | Shows how teams, services, priorities and stakeholders were organised |
| **Independent strategic exercise** | Shows judgement applied to a supplied or hypothetical brief; does not claim implementation |
| **Venture build** | Shows founder-led market, product, offer, brand and commercial execution |
| **Runnable proof** | Demonstrates logic using synthetic data and inspectable code |
