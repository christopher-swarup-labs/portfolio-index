## Phase 2 — Operating-system library

**Outcome:** The portfolio contains reusable frameworks, not only career stories.

Planned repositories:

1. `revenue-operating-system`
2. `lifecycle-governance`
3. `pipeline-truth`
4. `martech-governance`
5. `campaign-operations`

Each repository should contain:

- Executive overview
- Operating model
- Decision rules
- Roles and ownership
- Governance cadence
- Synthetic examples
- Measures and diagnostics
- Implementation roadmap

## Phase 3 — Runnable proof

**Outcome:** Important frameworks can be demonstrated, tested and inspected.

Initial tools:

- Lifecycle transition validator
- Pipeline quality scanner
- Martech rationalisation scorecard
- Campaign readiness checker
- GTM request triage workflow

Success criteria:

- Runs locally with simple instructions
- Uses synthetic data only
- Produces understandable outputs
- Contains tests for core logic
- Explains where human judgement remains required

## Phase 4 — Operator case studies

**Outcome:** Show repeatable leadership across different commercial situations.

Case-study themes:

- Fragmented GTM operating model
- Lifecycle and handoff redesign
- Trusted attribution and pipeline reporting
- Martech rationalisation
- Marketing Operations transformation
- Distributed delivery and governance
- Merger or organisational change
- AI-assisted operations with human accountability

## First measurable milestone

The first portfolio release is complete when it contains:

- One strong private landing page
- Three complete case studies
- Two reusable operating frameworks
- One runnable diagnostic
- A completed confidentiality review for every artefact
- A clear reviewer journey requiring less than 30 minutes
