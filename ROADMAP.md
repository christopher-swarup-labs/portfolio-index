## Phase 6 — Runnable proof

**Outcome:** Important frameworks can be demonstrated, tested and inspected.

Initial tools:

- Lifecycle transition validator
- Pipeline quality scanner
- Campaign readiness checker
- Martech rationalisation scorecard
- Lead scoring simulator
- Routing-rule tester
- CRM data-quality scanner
- GTM request triage workflow
- Handoff quality assessment
- Governed AI workflow demonstration

Success criteria:

- Runs locally with simple instructions
- Uses synthetic data only
- Produces understandable outputs
- Contains tests for core logic
- Explains where human judgement remains required
- Contains no copied employer logic or proprietary configuration

## First complete portfolio release

The first release is complete when it contains:

- One strong private landing page
- A complete capability and evidence map
- Five flagship operator case studies
- Three reusable operating frameworks
- Two runnable diagnostics
- One leadership and adoption case
- One governed AI case
- One clearly labelled independent strategic exercise
- One venture retrospective
- A completed confidentiality and provenance review for every artefact
- A role-specific reviewer journey requiring less than 30 minutes

## Delivery rule

Portfolio production will proceed collection by collection. A later, more visually attractive case must not displace a foundational capability that the Drive evidence proves.
