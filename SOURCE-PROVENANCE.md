# Source Provenance Register

## Purpose

This register records where portfolio ideas came from and how the source material was treated before publication.

It exists to prevent accidental copying of employer material, proprietary code, confidential data or private information.

## Treatment rules

| Source type | Allowed treatment | Direct upload allowed? |
|---|---|---|
| Personal professional knowledge | Reframe into original, company-neutral content | Yes, after review |
| CV and public professional profile | Use for role context and already public claims | Yes, after accuracy review |
| Historic employer documents | Extract concepts only; rebuild from scratch | No |
| Internal dashboards or datasets | Recreate with synthetic data and generic labels | No |
| Public research | Summarise with attribution where required | No direct copying |
| Owned venture material | Use selectively after confidentiality review | Sometimes |
| Source code from another repository | Link or reference only unless explicitly approved and licensed | No by default |
