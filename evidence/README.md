# Evidence and Verification

This directory contains the controls that separate professional narrative from claims that still require proof.

## Files

- [Claim Register](claim-register.md) — classifies employment context, scope, metrics, conflicts and exclusions.
- [Verification Backlog](verification-backlog.md) — records the decisions and evidence still required before publication.

## Operating rule

A claim is not made safe by placing it in a private repository.

Reviewer-facing content must distinguish:

- Public or approved professional context
- Approved professional material
- Safely generalised information
- Directional claims
- Claims requiring verification
- Excluded claims

Metrics that cannot be explained, sourced and attributed remain outside the reviewer narrative.
